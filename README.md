# Amazon SDE Portfolio - Abhinav

A modern, responsive portfolio website built with Next.js 14, TypeScript, and Tailwind CSS for Amazon SDE applicant Abhinav.

## Features

- **Modern Dark Theme** with blue accent (#2563EB)
- **Fully Responsive** design
- **Hero Section** with name and title
- **About Section** with photo and bio
- **Skills Section** showcoring Python, Java, AWS, React
- **Projects Section** with 3 detailed projects
- **Experience Timeline** 
- **Contact Form** with Formspree integration
- **SEO Optimized** with metadata
- **Accessibility Compliant** (WCAG 2.1 AA)
- **Performance Optimized** (Core Web Vitals)

## Tech Stack

- **Framework**: Next.js 14 with TypeScript
- **Styling**: Tailwind CSS
- **Icons**: React Icons
- **Form Handling**: Formspree
- **Images**: Next/Image
- **Code Quality**: ESLint & Prettier
- **Deployment**: Vercel

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/abhinavpadige4/amazon-sde-portfolio-abhinav.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) to view the site

## Deployment

This project is deployed to Vercel. To deploy your own version:

1. Push to GitHub
2. Import the repository on Vercel
3. Vercel will automatically detect it's a Next.js project and deploy it

## Environment Variables

Create a `.env.local` file with:
```
FORMSPREE_ENDPOINT=your_formspree_endpoint_here
```
